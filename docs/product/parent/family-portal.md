# Family Portal (Parent)

The Family Portal is a **calm window** onto one child. It is not the classroom PC and not the School Office. Parents cannot award stars, buy artifacts, or see the teacher’s private Chronicle.

**Pro and Elite.** One login per student, created under Teacher Settings → **Family Access**.

Mobile uses the same four tabs.

Header: **Family Portal**, the child’s name, **Refresh**, log out.

## The four tabs

| Tab | What families see |
|-----|-------------------|
| **Home** | Child card, total / monthly stars, attendance snapshot, homework count, shortcuts, latest results (if this class records tests or dictations), celebrations, **published** teacher notes |
| **Homework** | List and detail: title, body, date, teacher — the same Quest Assignment the teacher saved |
| **Progress** | Latest / average scores when assessments exist; attendance rate, lessons, absences; recent grades; full history modal |
| **Messages** | Inbox with school. Parents may send **General**, **Meeting request**, or **Question** |

If the class does **not** use tests or dictations, Progress speaks about notes and attendance instead of empty scores.

## What parents should understand (so teachers can say it)

- Stars are **character in English class**, not a second official grade.
- Monthly stars reset; total stars and guild belonging do not.
- Homework here is **the next lesson’s quest**, not a government worksheet dump.
- Messages are for meetings and questions, not for arguing a Prodigy result in the last week of the month.

## Dignity

The portal is **parent-safe by design**. Do not publish notes you would not read aloud at a desk with the child present. Celebrations (Hero of the Day, certificates) belong here; Skill Tree tactics do not.
