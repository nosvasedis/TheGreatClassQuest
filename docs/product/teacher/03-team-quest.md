# Team Quest

Team Quest is **class versus class**, inside the same **Quest League**. Sections of the same year (for example two Junior B groups) race each month to finish the map first. The winning class is celebrated in the first half of the **Ceremony of the Month**.

## Purpose

Build **social cohesion**. Nobody is left as a lonely high-scorer: every star a child earns also moves the *class token* along the road. The map makes “we are doing well” visible to a seven-year-old.

## What you see

- A **league banner** and a picker if you teach more than one league.
- The **League Map**: the illustrated parchment path through four zones (the same map art the class sees).
- Each class as a moving token. Position is **progress toward this month’s goal**, not raw star count alone. Labels are nudged so overlapping classes stay readable.
- A list of classes with stars, goal, **quest difficulty level**, and zone.
- **History** opens the **League Archive**, an atlas of past months. It opens on the latest finished month, in your league (or **All leagues**). Step through the months with the arrows or tap one on the dotted route; switch league with the chips, or **Find a class** by name. **Your parties** shows where each of your classes finished. Each league’s page shows the **Month champion**, a **race chart** of where every class stopped on the road (the realms and the goal flag), and then every class with its rank, % of goal, stars against goal, the realm it reached (or the stars it was short), the stars it needed to catch the class ahead, its difficulty level, “Goal reached” and the lesson days lost. Classes with no stars that month wait under **Still at the start line**. Only this school year’s finished months are charted.
- A reminder on **Home** when last month’s **Ceremony of the Month** has not been run yet; the ceremony opens from there.

Only classes that share the same **Quest League** race each other. Junior B does not race Class C.

### Quest Leagues (who races whom)

The league is the class’s age / curriculum band, set when you create the class. It is **not** a guild and **not** a Hero Path class.

Pre-Junior (5–7) · Junior A (7–8) · Junior B (8–9) · A (9–10) · B (10–11) · C (11–12) · D (12–13).

A class’s progress is its stars this month (including Team Quest bonuses such as Pathfinder’s Map or Quiz bonuses) divided by this month’s goal. The four lands sit on the map above, as they do in the classroom: **Bronze Meadows** from 0%, **Silver Peaks** from 30%, **Golden Citadel** from 60%, **Crystal Realm** from 85%.

Places are never shared: if two classes sit on the same percentage, the app still gives each one its own place.

## Quest difficulty levels

Every class has a **quest level** that starts at **Level 1**. Each time the class **reaches this month’s goal**, its level goes up by one, so later months ask a little more. The level shows as a badge on the tab and as a chip in the ceremony (Levels 1–6: 🌱 💧 🛡️ 🔮 🔥 🐉; the display stops at 6). Past months in History and the ceremony show the level that was true *that* month, not today’s harder one.

The level has nothing to do with Quest League: two Junior B classes can sit at different levels if one finished the map more often.

## How the monthly goal is set

You do not type the goal. The Quest works it out, so that a class with many holidays is not punished and a class that has already conquered the map is not racing an easy target.

For each student the goal starts at **18** stars, plus **2.5** more for every level above Level 1. That figure is then adjusted for holidays (see below), multiplied by the number of students, and rounded. The class goal **never falls below 18** stars in total (even an empty class is treated as 18).

### Holidays and cancelled lessons

**Days lost** this month are counted from two things:

1. The days of this month that fall inside a **school-wide holiday**, which the School Office sets under School Details; **plus**
2. This class’s **cancelled lessons** that month that are *not* already inside a holiday (cancelled in the Day Planner).

**How much of the month counts**

- **June** always counts as half a month (**0.5**), because term ends. This is not optional.
- Any other month: the days left after the days lost, divided by the days in the month, but never below 60% and never above 100%. A class cannot be asked for a full goal after a long Easter break, and a short holiday cannot shrink the goal below 60%.

Home and Team Quest both show a small calendar or umbrella cue when the goal has been adjusted for days lost.

A worked example (not a promise of any particular class’s number): 10 students at Level 1 in a full month have a goal of about **180** stars. The same class at Level 3 (two levels up) has about **230**. In June those figures are halved, and never go below 18.

## What you can do

- Watch the race with the class on the projector (or on this tab).
- Open **History** to recall last month’s finishing order.
- Run the **Ceremony of the Month** when it is offered — that ceremony *includes* Team Quest ranks and then switches to Prodigy (see the ceremony chapter).
- Select a class in the header so the map highlights the group in front of you.

You do not “award Team Quest points” by hand. Award Stars, Pathfinder’s Map, Quiz of the Week, and some Fortune’s Wheel and event bonuses add the numbers for you.

## How this feeds the rest of the Quest

| Input | Effect on Team Quest |
|-------|----------------------|
| Ordinary stars on Award Stars | Monthly stars for every student, summed for the class |
| Pathfinder’s Map | Instant **+10** class quest stars, once per class per month |
| Quiz of the Week | Extra class quest bonus by performance tier |
| 2x Star Day / Reason Bonus Day | More stars that month, so the token moves faster |
| Holidays / cancelled lessons | Lower goal, fairer race |

Team Quest **resets each calendar month**. Guild Hall does **not**. Do not mix the two races in a parent meeting.
