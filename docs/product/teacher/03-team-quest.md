# Team Quest

Team Quest is **class versus class**, inside the same **Quest League**. Sections of the same year (for example two Junior B groups) race each month to finish the map first. The winning class is celebrated in the first half of the **Ceremony of the Month**.

## Purpose

Build **social cohesion**. Nobody is left as a lonely high-scorer: every star a child earns also moves the *class token* along the road. The map makes “we are doing well” visible to a seven-year-old.

## What you see

- A **league banner** and a picker if you teach more than one league.
- The **League Map**: the illustrated parchment path through four zones (the same map art the class sees).
- Each class as a moving token. Position is **progress toward this month’s goal**, not raw star count alone. Labels are nudged so overlapping classes stay readable.
- A list of classes with stars, goal, **quest difficulty level**, and zone.
- **History** of past months.
- A glow / Home reminder when last month’s **Ceremony of the Month** has not been run yet.

Only classes that share the same **Quest League** race each other. Junior B does not race Class C.

### Quest Leagues (who races whom)

The league is the class’s age / curriculum band, set when you create the class. It is **not** a guild and **not** a Hero Path class.

Nursery (5–6) · Pre-Junior (6–7) · Junior A (7–8) · Junior B (8–9) · A (9–10) · B (10–11) · C (11–12) · D (12–13) · E (13–14) · Lower (14–15) · Proficiency (15+).

Progress = this class’s monthly stars (including Team Quest bonuses such as Pathfinder’s Map or Quiz bonuses) ÷ this month’s goal. The four lands sit on the map above, as they do in the classroom: **Bronze Meadows** from 0%, **Silver Peaks** from 30%, **Golden Citadel** from 60%, **Crystal Realm** from 85%.

Ranks never tie: if two classes sit on the same percentage, the app still gives unique places.

## Quest difficulty levels

Each class has a stored **difficulty** that starts at **0**. The tab badge shows **Level 1** (difficulty + 1). Ceremony chips show Levels **1–6** (🌱 💧 🛡️ 🔮 🔥 🐉); the chip display clamps at 6.

When the class **reaches this month’s goal**, the Quest records a completion and **adds 1** to difficulty. Later months therefore ask a little more. Past months in History / the Ceremony reconstruct the difficulty that was true *that* month (they do not pretend today’s harder level was always the goal).

This is independent of Quest League. Two Junior B classes can sit at different Levels if one finished the map more often.

## How the monthly goal is set

You do not type the goal. The Quest computes it so a class with many holidays is not punished, and so a class that already conquered the map is not racing an easy target.

For each student the app starts from **18** stars, then adds **2.5 × difficulty**. That per-student figure is multiplied by a **month modifier**, then by the number of students, then rounded. The class goal **never falls below 18** stars in total (even an empty class is treated as 18).

### Holidays and cancelled lessons

**Days lost** this calendar month =

1. Overlap of **school-wide holiday ranges** (Secretary → School Office → School Details) with this month, counted as calendar days, **plus**
2. This class’s **cancelled lessons** in the month that are *not* already inside a holiday range (Day Planner / schedule override).

**Month modifier**

- **June** is always **0.5** (half a month). Term-end is real life; this is not optional.
- Any other month: `(days in month − days lost) ÷ days in month`, then **clamped between 60% and 100%**. A class cannot be asked for a full goal after a long Easter, and a tiny holiday cannot shrink the goal below 60%.

Home and Team Quest both show when the goal was adjusted (calendar / umbrella cue).

Worked shape (not a promise of a specific class’s number): 10 students at Level 1 (difficulty 0) in a full month → about **180** stars. The same class at difficulty 2 → about **230**. In June, those figures are halved, then floored at 18.

## What you can do

- Watch the race with the class on the projector (or on this tab).
- Open **History** to recall last month’s finishing order.
- Run the **Ceremony of the Month** when it is offered — that ceremony *includes* Team Quest ranks and then switches to Prodigy (see the ceremony chapter).
- Set **Active class** so the map highlights the group in front of you.

You do not “award Team Quest points” by hand. Award Stars, Pathfinder’s Map, Quiz of the Week, and some Fortune’s Wheel / event bonuses write the numbers.

## How this feeds the rest of the Quest

| Input | Effect on Team Quest |
|-------|----------------------|
| Ordinary stars on Award Stars | Monthly stars for every student, summed for the class |
| Pathfinder’s Map | Instant **+10** class quest stars, once per class per month |
| Quiz of the Week | Extra class quest bonus by performance tier |
| 2x Star Day / Reason Bonus Day | More stars that month, so the token moves faster |
| Holidays / cancelled lessons | Lower goal, fairer race |

Team Quest **resets each calendar month**. Guild Hall does **not**. Do not mix the two races in a parent meeting.
