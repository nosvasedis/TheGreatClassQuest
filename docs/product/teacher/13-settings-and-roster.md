# Teacher Settings, roster, Family Access, and Quiz setup

The cog in the header opens **Teacher Settings** on **My Classes**. My Classes is **here**, not on the ten-tab bar. The hidden Student Roster is the same world, reached from a class’s **Manage Students**.

## Purpose

Build the school-year stage: classes, people, dates, parent doors, and (on Elite) the weekly quiz. Then go back to Award Stars and teach.

## Subtabs

Choose a section from the **dropdown** at the top (no sideways scroll). On a phone the same names open from a **sheet**.

| Subtab | What it is |
|--------|------------|
| **My Classes** | Opens first. Create/edit classes and open the roster |
| **Student Tools** | Repair stars and Gold without pretending it was today’s lesson |
| **My Planning** | Each class’s **final lesson day** (Pro) |
| **Profile** | Your **display name** (Quest Master name on logs) |
| **Class Grading** | Override secretary assessment defaults for *your* class (Pro) |
| **Family Access** | Parent username and password per child (Pro) |
| **Quiz** | Build Quiz of the Week (Elite) — play it on **Home** |
| **Market** | Repair Seasonal Treasures and Festival Stall (Elite) |

### Student Tools

- **Student Star Manager** — pick a student. **Add Historical Award** (date, stars, reason including Welcome Back and Manual Correction) writes a real log. **Direct Score Override** (Today / Monthly / Total) changes the number **without** a log — use only to repair accidents.
- **Coin Purse Manager** — set current Gold.
- **Familiar Sprite Forge** (Elite) — regenerate a Familiar sprite if art failed.

### My Classes

Create a class: name, **logo** (picker, not a dump of icons), schedule days and times, **Quest League** (age/difficulty). That league chooses the map peers, Market tone, Guild quiz language, and certificate voice.

Per class: **Report** (AI weekly summary + suggested mini-quest on Elite), **Edit**, **Manage Students**, delete with care.

## Profile

Your **display name** — the Quest Master name on logs, ceremonies, and the Adventurer’s Guide greeting. Save it here.

## Manage Students (the roster)

This is the class list you live in: avatar, name, Hero Class / title, guild mark, and a row of **the same buttons the classroom uses**.

**New Student** on this roster adds a name to *your* class. The School Office can also **Add a new student** from Admin → School Year; that hero is still **yours** to teach.

If returning heroes are still waiting for a class, a compact **Student setup** bar appears above the roster. It starts collapsed. Open it to search, tick suggestions (by last year’s league), and **Place Selected**. This is the teacher’s seat for last year’s students — not the School Office **Student placement** wizard, and not **Add a new student**.

| Button | Looks like | What it does |
|--------|------------|----------------|
| **Guild** | House emblem, or a small wizard hat if they have no house yet | Opens the **Guild Sorting Quiz** (Pro). Starter sees a locked hat. |
| **Choose Hero Class** | Indigo **shield**, only if they have no Hero Class yet | Opens the **Hero Class** ceremony (Pro). Changing an existing class stays behind **Edit → Hero Path**. |
| **Skill Tree** | Purple **sitemap**. **Pulses** when a new branch is waiting | Opens the Skill Tree (Pro). See the Hero Path chapter. |
| **Hero’s Chronicle** | Green **book** | Private notebook for this child (below). |
| **Parent Access** | Sky **shield** | Jumps to Family Access for this child (Pro). |
| **Avatar Forge** | Magenta **astronaut** | Chibi avatar from type, colour, accessory (Elite). Locked on other plans. |
| **Certificate** | Indigo **award** | Praise PDF. |
| **Move** | Yellow **people-arrows** | Send the child to another class you teach. |
| **Edit** | Cyan **pencil** | Profile, Special Dates, Hero Path, Quick Hub. |
| **Delete** | Red **bin** | Asks twice. Recovery, not a weekly habit. |

**Edit student → Special Dates:** birthday and nameday. Magic wand → **AI Nameday Lookup** (Greek Orthodox εορτολόγιο) on Elite.

**Edit student → Hero Path:** a compact summary of the current class (or No Class) plus **Choose Hero Class** / **Change Hero Class** / **Your Path**. That opens the ceremony on the board — preview, then **Swear this Path**. Leave them unassigned for No Class. Skill Tree stays on this tab. They keep the class they have. Each school year they may change it twice; the second change locks the path until the next school year. The Hero Path chapter shows the screen.

**Quick Hub:** the same deep tools without leaving the edit window.

AI tools (Forge, Oracle, nameday, reports, certificates, Restock) are **one family**: they read the same roster identity. A name change here is the name on logs, ceremonies, and the Family Portal.

## Hero’s Chronicle

The green book on the roster. This is **your** notebook — not the Adventure Log the class hears, and not the Family Portal.

**History of Deeds** on the left. **New Entry** on the right. Categories in the app:

- 📓 **General**
- 🎓 **Academic**
- 🎭 **Behavior**
- 💬 **Social**
- 🎯 **Goals**

Families never see private notes unless you **Publish to Portal** an Oracle page. You can edit or delete an entry.

**The Oracle** (Elite): Parent Summary, Teacher Strategy, Traits & Trends (strengths / weaknesses), and Hero’s Goal. It reads notes, trial scores, and stars. You still decide what to keep.

**Hero’s Chronicle notes** exist on every subscribed plan. The Oracle is Elite.

## My Planning

Only the **last lesson day** for the class in the header. After that date the class leaves day-by-day schedules. **Holidays belong to the Secretary.**

## Class Grading

**My classes** first: pick a class, then **Tests** or **Dictations**. Leave **Use school defaults** on unless this group should sit different papers. **School picture** is the Secretary’s read-only league setup. Save My Class Grading.

## Family Access

One parent login per student. Families see progress, homework (from Quest Assignment), celebrations, and **published** notes — not your private Chronicle. Pro and Elite.

## Quiz (Elite)

Curriculum chips, keywords, **Generate**, history, reset this week. Question count scales with class size. Play on Home, first lesson of the week, during lesson time. Full reward tables live in the Home chapter.

## Market (Elite)

This class’s Seasonal Treasures and Festival Stall (header class). **New picture** keeps the piece and redraws art. **Replace this treasure** invents a new piece of the same rarity. Save name, description, Gold, and remaining copies. Remove takes it off the stall. Incoming Restock pieces appear under **Coming in**.

## How this feeds the rest of the Quest

Without a class and roster, Award Stars has no clouds. Without Hero Path and Guild Quiz, identity tools stay dormant. Without Family Access, parents cannot follow the homework you typed at the end of the lesson. Settings is the **stage crew**; the play happens on the ten tabs.
